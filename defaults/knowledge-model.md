# Default Knowledge Model

## Purpose

This model defines the shared meaning of durable Scaffold knowledge. It is authoritative only when a project does not provide `.scaffold/knowledge-model.md`.

## Concepts

- **Actor**: a person, role, system, or external party with an interest or responsibility.
- **Goal**: an outcome an Actor seeks.
- **Motivation**: the reason a Goal matters.
- **Use Case**: an interaction that helps an Actor achieve a Goal.
- **Requirement**: an observable obligation derived from a need, decision, or constraint.
- **Capability**: an ability the solution provides.
- **Decision** and **Design**: a chosen approach and its reasoning.
- **Verification**: evidence that a requirement, design, or control is satisfied.
- **Security Control** and **External Contract**: governing constraints on behavior or integration.

## Boundaries

- **Problem Space** records actors, motivations, goals, use cases, and requirements without prescribing a solution.
